Medical Imaging FLAGSHIP EXAMPLE — MedSAM Tumor Segmentation from CT

How do I use MedSAM to segment a tumor from a CT volume in MATLAB? I have a NIfTI file with the CT scan. I want to interactively mark a few points on the tumor in one slice, then propagate the segmentation to the full 3D volume.
With Skill (366 lines)
%% Load with spatial referencing (Critical Rule 2)
V = medicalVolume(niftiFile);

%% Load MedSAM — correct function name
model = medicalSegmentAnythingModel(
    'ExecutionEnvironment', 'gpu');

%% Extract seed slice in patient coordinates
seedImg = double(extractSlice(V, seedSlice, 'transverse'));

%% Compute embeddings — correct method
embeddings = extractEmbeddings(model, seedImg);

%% Segment — imageSize is REQUIRED 3rd arg
mask = segmentObjectsFromEmbeddings(
    model, embeddings, imageSize, ...
    ForegroundPoints=fgPoints, ...
    BackgroundPoints=bgPoints);

%% 3D propagation: seed-and-propagate
for k = (seedSlice+1):V.NumTransverseSlices
    % Derive centroid from previous mask
    props = regionprops(prevMask, 'Centroid');
    fg = props(1).Centroid;
    emb = extractEmbeddings(model, sliceImg);
    mask = segmentObjectsFromEmbeddings(model, ...
        emb, imageSize, ForegroundPoints=fg);
end

%% Save with spatial geometry preserved
segVol = medicalVolume(uint8(mask), V.VolumeGeometry);
segVol.Modality = 'SEG';
write(segVol, 'tumor_seg.nii.gz');

Uses medicalSegmentAnythingModel (correct function name), extractEmbeddings (correct method), imageSize as required 3rd argument, medicalVolume for all I/O, extractSlice with proper orientation, and saves output with spatial geometry. 10-step clinical-grade pipeline.

Wavelet Differentiable Wavelet Transform (dldwt) in Deep Learning

Write MATLAB R2025b code to use the differentiable discrete wavelet transform (dldwt) inside a deep learning pipeline. Show how to decompose an image using dldwt and reconstruct with dlidwt. Explain the output format.
With Skill
% dldwt returns exactly 2 outputs: [A, D]
imgDL = dlarray(img, 'SSCB');
[A, D] = dldwt(imgDL, 'db4');

% D is a SINGLE 3D dlarray with subbands
% concatenated along channel dimension:
%   D(:,:,1,:) = Horizontal details
%   D(:,:,2,:) = Vertical details
%   D(:,:,3,:) = Diagonal details

% Reconstruct
imgRec = dlidwt(A, D, 'db4', ...
    OutputSize=size(img,1:2));

Correctly documents that D is a single dlarray with subbands stacked along the channel dimension. Uses SSCB format. Verified by runtime: [A,D] = dldwt(x) returns D as [4x4x3].

Stats-ML Survival Analysis — Drug A vs Drug B

Write MATLAB R2025b code to compare survival between two treatment groups (Drug A vs Drug B). Plot Kaplan-Meier curves and test if the difference is statistically significant.
With Skill
% IMPORTANT: logrank() does NOT exist in MATLAB
% Use coxphfit with group covariate instead

% Kaplan-Meier with confidence intervals
[f, x, flo, fup] = ecdf(time, ...
    'Function','survivor', ...
    'Censoring', ~logical(event));

% Cox regression (log-rank equivalent)
[b, logl, H, stats] = coxphfit(
    groupNumeric, T, ...
    'Censoring', censoringVec);

% Hazard ratio with CI
HR = exp(b);
HR_CI = exp(b ± 1.96*stats.se);

% Proportional hazards check
% log-log plot: log(-log(S(t))) vs log(t)

noise_real = sigma * randn(size(mri));
